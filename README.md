# AI-Companion

ИИ-компаньон для одиночной игры в **Minecraft Java Edition 1.21.1** с **NeoForge**.
Версия мода: **0.0.3**. Номер меняется только по явному решению владельца.

Олег общается по-русски, следует за игроком, добывает ресурсы (в том числе песок, красный песок, гравий и кремень лопатой, стекло из песка, огниво из железа и кремня), создаёт предметы по настоящим рецептам, переносит вещи, работает с сундуками и печами, строит небольшой деревянный дом и помогает в бою. Возможности ограничены доступными материалами и маршрутами; произвольные большие постройки и полноценная самостоятельная игра ещё не реализованы.

## Установка

1. Подготовьте отдельный профиль Minecraft **1.21.1** с NeoForge **21.1.262 или совместимым более новым 21.1.x**.
2. Откройте **Releases** справа на странице и скачайте `aicompanion-0.0.3.jar` из **Assets**.
3. Положите JAR в папку `mods` этого профиля и запустите игру. Для экспериментов используйте копию мира.
4. Откройте настройки AI Companion и введите **свой** ключ OpenRouter и модель. Для голоса добавьте **свой** Inworld Basic credential и voice ID; без него на Windows и macOS Олег говорит установленным русским системным голосом (выключается в «Поведении»). В опубликованном проекте чужих ключей нет.
   Вместо OpenRouter можно указать в поле «Адрес сервера модели» свой сервер с OpenAI-совместимым API, например локальную Ollama (`http://localhost:11434/v1`) или LM Studio (`http://localhost:1234/v1`), и название загруженной в него модели. Локальному серверу ключ не нужен; модель должна уметь вызывать инструменты или отвечать JSON. Инструкция Олега длинная: в Ollama увеличьте длину контекста (переменная `OLLAMA_CONTEXT_LENGTH`), иначе её начало обрежется.

### Прямое подключение OpenAI

Если у вас уже есть API-кредиты OpenAI, их можно использовать прямо в моде: отдельный аккаунт и баланс OpenRouter для этого не нужны. Нужен API-ключ проекта в организации OpenAI, на которую начислены кредиты, и доступ к выбранной модели.

В настройках AI Companion укажите:

- **Ключ API** — свой ключ OpenAI.
- **Адрес сервера модели** — `https://api.openai.com/v1`.
- **Модель** — `gpt-6-luna` или `gpt-6.1-terra`.

Нажмите **Сохранить**. Мод автоматически использует Responses API: Олег может разговаривать и передавать игровые команды. `openrouter/auto` выбирает модель только через OpenRouter; для прямого OpenAI нужно указать её ID. Озвучка и распознавание речи настраиваются отдельно, как и раньше.

Ключ остаётся в локальных настройках Minecraft. Диалог и текущий игровой контекст отправляются в OpenAI; мод передаёт `store: false` и не создаёт серверную цепочку разговоров. Это не отменяет правил обработки данных самим провайдером. Незавершённый или некорректный план не запускается.

Правила модели действуют и здесь, в формате Responses: «Размышление модели» выключено по умолчанию (`reasoning.effort` «none»), включённое оставляет собственный уровень модели; температура и top_p отправляются как заданы, а модель, которая их не принимает, отвечает своей ошибкой; предел ответа тот же — 90 секунд на попытку, бюджеты те же, а пустой оборванный ответ повторяется один раз с вдвое большим бюджетом (это вторая попытка, поэтому худший случай — две). На OpenRouter выключенное размышление передаётся его собственным полем `reasoning.effort` «none»: там токены размышления входят в `max_tokens`, а `chat_template_kwargs` OpenRouter не документирует.

**Code → Download ZIP** скачивает исходники для разработки. Для игры нужен JAR из Releases или самостоятельная сборка.

## Управление

- **C** — чат и доступ к настройкам.
- **J** — задачи, их состояние, приоритет и отмена.
- **V** — удерживать для записи голоса, отпустить для отправки.
- **ПКМ по Олегу** — его инвентарь.
- **G** — маркер компаньона.
- **N** — полоска настроения Олега справа: его настроение сейчас, связь с тобой и черты характера.

Клавиши можно изменить в настройках управления. Например: «следуй за мной», «стой здесь», «иди ко мне», «веди на северо-восток», «добудь 10 камня», «сделай себе каменную кирку», «сложи ресурсы в сундук». Некоторые прямые команды работают без OpenRouter; свободный диалог и сложные планы требуют настроенного провайдера. Голос требует Inworld. Условия и стоимость внешних сервисов определяются самими провайдерами.

## Вечер у костра

Если постоять у горящего костра около полминуты, когда Олег ничем не занят и монстров рядом нет, он сам садится на землю по другую сторону огня, достаёт гитару и играет. По просьбе («сыграй», «сыграй на гитаре», «поставь костёр и сыграй», «посидим у костра») он садится у горящего костра рядом с тобой, а если такого нет — ставит свой костёр из сумки. Костёр для музыки не обязателен, он только добавляет уюта: без него Олег садится на свободное место рядом с тобой, лицом к тебе, и играет. Пока он играет, можно попросить другую мелодию («сыграй грустное», «повеселее», «давай другую»): он сменит её, не вставая с места, и спокойно поддержит разговор на любую тему.

Команда `/sit` усаживает тебя самого на блок, на котором ты стоишь, — например, рядом с Олегом у огня. Встать: Shift или ещё раз `/sit`.

Звучат настоящие записи сольной акустической (классической) гитары без слов, но своей музыки мод не везёт: в JAR её нет вовсе. Все записи лежат в папке `config/aicompanion/music` (рядом с настройками игры), и каждый файл `.ogg` в ней Олег сможет сыграть, а `.mp3` — после того, как один раз переведёт его в Ogg Vorbis рядом с ним (рядом останется служебная запись `.stamp`), а длину он читает из самой записи. Готовый набор из семи записей — в папке `music/` репозитория и отдельным архивом `oleg-guitar-tracks.zip`, который собирает только `scripts/make-music-pack.sh`; в архиве уже готовая структура `config/aicompanion/music`, и к выпуску мода его прикладывают вручную. Папка читается при запуске игры, при перезагрузке ресурсов и при входе в мир — команд для этого не нужно. На сервере записи нужны и серверу, и клиенту: сервер по своей папке выбирает мелодию, клиент по своей её играет, поэтому одинаковый набор должен лежать с обеих сторон. Пока папка пуста, Олег играет стандартную музыку Minecraft (пластинки), и об этом он ничего не говорит. Настроение записи задаётся числом в начале имени файла — от 1 (самая грустная) до 9 (самая весёлая): 1–4 он считает спокойными и грустными, 5 — серединой, 6–9 — весёлыми; по «сыграй грустное» он выберет запись с 1–4, по «повеселее» — с 6–9, а если подходящих нет, честно скажет об этом и сыграет любую. Все записи — общественное достояние, CC0, CC BY или CC BY-SA; авторы и лицензии перечислены в `music/CREDITS.md`, там же ссылки на исходники. Вечер у костра, `/sit` и записи написал 0r1k (PR #142). Громкость регулирует ползунок «Проигрыватели/нотные блоки». На весёлых мелодиях Олег улыбается, на спокойных и грустных лицо обычное; пока играет, он смотрит только на огонь, а без костра — перед собой. Гитара — его личная вещь: в инвентарь она не попадает. Музыка заканчивается от любого поручения, от «хватит играть» или «стоп», когда ты уходишь от костра, костёр гаснет или рядом появляются монстры. Выключатель «Олег играет у костра» — в «Поведении»: выключенный, он не играет ни сам, ни по просьбе.

## Постройки

Олег строит дом 5×5 из досок и здания деревень Minecraft: их шаблоны уже лежат в самой игре, ничего скачивать и класть в папки не нужно. В наборе 16 зданий: 12 домов (деревенские, бревенчатый, пустынный, саванные, таёжные, снежный), три кузницы (две равнин и одна тайги) и храм саванны. Набор закрытый: в него попали здания, которые Олег достраивает из полной сумки с землёй и инструментами.

Как попросить:

- «построй дом» (а также «маленький», «небольшой», «деревянный дом») — прежний дом 5×5. Работает и без модели.
- «построй кузницу», «построй храм» — Олег сам выберет здание этого вида: сначала то, что подходит к местности, где ты стоишь, иначе первое из набора. Работает и без модели.
- «построй пустынный дом», «построй кузницу равнин 2» — именно это здание, имя точное. Тоже без модели.
- Всё остальное («построй замок», «построй библиотеку») уходит к модели. Она знает набор; если такого здания нет, Олег скажет об этом и назовёт похожие.
- «дострой», «достраивай», «продолжи стройку» (и с названием: «дострой кузницу») продолжают недостроенное на том же месте, в том числе после выхода из мира, и никогда не начинают ничего нового: если недостроенного здесь нет, Олег так и скажет (а если оно осталось в другом измерении, скажет где). Без названия — то, что он строил последним; «дострой дом» — сначала дом 5×5, потом дом из набора; с названием или видом — только это здание. «Стоп» останавливает стройку, ничего не теряется. Если попросить другое здание, пока прежнее недостроено, прежнее остаётся, пока ты не выберешь место для нового (отменил выбор — оно твоё), и бросается только когда место подтверждено; то же здание он продолжает.

Здание выбирается в окне «Постройки»: оно открывается само, когда просишь «построй храм» (сразу на этом здании), и кнопкой «Постройки» в окне задач (**J**). Слева список по видам, справа размер и таблица материалов: сколько надо, сколько в сумке Олега и кто достаёт недостающее — он сам или ты. «Строить» закрывает окно и запускает тот же заказ, что и фраза; «Отмена» и **Esc** снимают заказ, мир и сумка остаются как были. Окно проходится с клавиатуры: **Tab** — между списком и кнопками, **↑**/**↓** — по списку, **Enter** или пробел — нажать, **PageUp**/**PageDown** — длинную таблицу. Олег говорит одну короткую фразу, а на земле появляется полупрозрачный призрак. Пока ты не подтвердишь место, он ничего не ставит и не добывает. Пока призрак на земле, в левом верхнем углу экрана подсказка с названием и клавишами (меняются в настройках управления): **Enter** — строить здесь, **Backspace** — отмена, **R** — повернуть на 90°, **H** — снова вести призрак за прицелом, стрелки — сдвинуть, **PageUp** и **PageDown** — выше и ниже.

Сам Олег расчищает площадку, добывает дерево, камень и землю, делает из них доски, ступени, плиты и двери по рецептам, а для высоких стен и крыши ставит леса из земли и потом разбирает их. Блоки он ставит только из своей сумки. Что добыть сам не может (например, стекло, факелы, кровати), он перечисляет и просит положить в сумку; всё остальное достраивает, а дверь ставит последней, чтобы не закрыть себе путь к тому, что принесёшь; после «дострой» он продолжает. Если дерева, камня или земли рядом нет, он называет и это. Сундуки и печи в постройке остаются пустыми, жители и животные не появляются. Если место далеко, он сначала идёт к нему пешком; если пути туда нет, так и говорит и ждёт «дострой». Деревья, которые нависают над крышей и растут у стен, он срубает (высокие ветки — с лесов из земли), а чужие постройки не трогает и называет, что мешает. Камень недостроенного здания он держит для него только пока строит его; факелы, которые ты дал для недостроенной постройки, он бережёт для неё и не тратит на свет по пути.

## Долгие цели

Большой заказ на много игровых часов Олег ведёт сам, по этапам, и хранит цель в сохранении мира: она переживает перезапуск игры. Выбор закрытый, из трёх целей; Олег не придумывает свои. Какой этап выполнен, он проверяет по фактам игры, а не на слово.

- **Снаряжение** — полный набор: кирка, меч, шлем, нагрудник, поножи, ботинки. По умолчанию железный, можно попросить алмазный: «сделай себе железную броню», «собери себе алмазную броню».
- **Подготовка к Незеру** — алмазное снаряжение, запас готовой еды, булыжник, огниво: «подготовься к Незеру». Огниво Олег делает сам из железного слитка и кремня, который выкапывает из гравия.
- **Победа над драконом Края**: «иди убей дракона». Олег сделает ту часть, которую уже умеет, и назовёт, чего пока не умеет.

Цель ставится через модель, поэтому нужен настроенный провайдер. В ответе Олег говорит, что сделает и чего пока не умеет. Одновременно ведётся одна цель и может быть отложена ещё одна.

Управление целью работает и без провайдера:

- «как там цель» — рассказать, как идут дела.
- «отложи цель» — отложить; она ждёт, пока ты не скажешь вернуться.
- «продолжай», «вернись к цели» или «продолжай цель» — продолжить.
- «отмени цель» или «забудь про цель» — отменить насовсем.

Обычная просьба прерывает цель, и после неё Олег возвращается к цели сам. Режимы («следуй за мной», «стой здесь», «защищай меня») и «стоп» только останавливают текущее дело: цель ждёт, пока ты не скажешь вернуться к ней. Опасность (бой, огонь, лава) ставит цель на паузу; если она не отступает больше минуты, Олег останавливается и просит помощи. Если Олег погиб, он один раз пробует подобрать свои выпавшие вещи или говорит, где они остались.

На экране задач (**J**) цель стоит первой строкой, под ней этапы: ✔ сделано, ▶ сейчас, · дальше, ✖ не умею, ! помеха. Кнопки: «Продолжить», «Отложить», «Отменить цель». Состояние цели входит в игровой контекст для модели, поэтому на вопросы вроде «сколько осталось» Олег отвечает по нему.

## Конфиденциальность

Ключи вводятся локально и хранятся в `config/aicompanion-client.toml` папки Minecraft. Этот файл, его резервные копии, миры, журналы и прежняя локальная история Git не включены в публикацию.

При включённых функциях OpenRouter (или сервер из поля «Адрес сервера модели») получает текст диалога и игровой контекст (например, инвентарь и обстановку); ключ API тоже отправляется на этот адрес (только по `https` или на этот же компьютер; ключ OpenRouter — только в OpenRouter). Inworld получает аудио для распознавания и текст для озвучки. Не вводите секреты в игровой чат. Это обращения к выбранным провайдерам, а не отправка ключей автора мода другим игрокам.

Долговременная память хранится в сохранении мира (`aicompanion_bonds`): воспоминания о вас, несколько последних реплик (известные виды ключей и паролей маскируются как «[скрыто]», это не гарантия), журнал ещё не сжатых реплик (до 40, с той же маскировкой), ступень отношений, недавние события, время последней встречи, а также характер Олега, подстроенный под вас, его темы для разговора, придуманные по вашим беседам, и список уже поднятых тем. В журнал и в последние реплики попадают реплики игрока, ответы Олега на них, в том числе текст модели, который сопровождает план, и темы, которые Олег заводит сам. Не попадают реплики Олега о событиях и о его собственных делах, отчёты о работе, местные короткие подтверждения команд и команды памяти («что ты обо мне помнишь», «забудь всё»). Сам живой чат уходит в OpenRouter как есть, без маскировки; этот журнал (уже с маскировкой) уходит туда на сжатие в воспоминания каждые 12 реплик игрока и один раз в начале следующей сессии, чтобы сжать хвост прошлой; вместе с журналом уходят нынешние черты характера Олега и его темы, а в ответ он получает новые темы и сдвиг черт. Строки уходят из журнала, когда ответ модели на сжатие обработан, даже если воспоминаний из него извлечь не удалось; при ошибке сети, пустом или оборванном ответе строки остаются до следующей попытки. Переключатель «Память» в настройках останавливает запись реплик, журнала и воспоминаний, сжатие и подстановку памяти в запросы — без памяти Олег не заводит своих тем и говорит с обычным характером, — но события, ступень отношений и время последней встречи сервер продолжает записывать в мир. Реплики прошлой сессии, уже подставленные в текущий разговор, остаются в запросах до выхода из мира; «забудь всё» убирает их сразу. Фразой «забудь всё» стираются воспоминания, предпочтения, реплики, журнал ещё не сжатых реплик, характер и темы Олега — и при выключенной памяти; ступень отношений, недавние события, время последней встречи и общие дела остаются, а удаление мира стирает всё. Журналы диагностики и игры и окно чата «забудь всё» не очищает и не отзывает то, что уже ушло провайдерам: реплики и игровой контекст, отправленные в OpenRouter, голос и текст озвучки, отправленные в Inworld; запрос, отправленный до «забудь всё», при повторе после сбоя связи уходит ещё раз с прежним содержимым.

Локальная диагностика включена по умолчанию и может содержать разговоры, координаты и инвентарь. Чтобы отключить новые записи, задайте `diagnosticLogging = false` в локальных настройках. Не публикуйте эти журналы целиком. Подробности: [SECURITY.md](SECURITY.md).

## Анекдоты и байки

Перед каждой встроенной или пользовательской историей Олег говорит: «Внимание, анекдот».
После объявления выдерживается двухсекундная пауза, затем звучит сама история.

В «Поведении» включаются «Анекдоты» и настраивается пауза. Во встроенном наборе
40 оригинальных баек про Minecraft в атмосфере посиделок у костра: по пять про лес,
шахту, деревню и торговлю, Незер, Энд, путешествия, криперов и выживание.
Гитара пока не интегрирована. Окружение и события последних 10 минут повышают
вероятность подходящей истории: например, добыча руды, торговля или гибель от крипера.
Это случайный выбор готового текста, без генерации моделью и расхода токенов.
Озвучка использует обычный выбранный движок (локальный голос либо Inworld).

По умолчанию пауза **5–10 минут активной игры**, одинаково с файлом и без него.
`jokeIntervalMinutes = 5` задаёт минимум, максимум — вдвое больше; доступно 1–60.
Первый анекдот тоже ждёт паузу. Бой, работа, меню, разговор и звучащая речь мешают
начать анекдот, но не расходуют его. Общий выключатель самостоятельных реплик
отключает и анекдоты. Одна история не повторяется в течение часа и дважды подряд.
Перезагрузка файла и смена языка сохраняют таймер и историю; выход из мира очищает их.
Ограничение обычных коротких реплик в 15 слов не относится к анекдотам.

### Свой файл

Откройте «Поведение» → «Свои анекдоты: файл и перезагрузка» → «Открыть файл».
При первом открытии появится `config/aicompanion-jokes.txt` в папке Minecraft
с инструкцией. Файл необязателен и дополняет встроенный набор.
После сохранения нажмите **«Перезагрузить»**: перезаход в мир не нужен.
Статус показывает количество принятых историй и причины пропуска остальных.
При ошибке чтения последний рабочий набор сохраняется.

- UTF-8 (BOM допустим), не более **2 МиБ** на файл и **10 000 уникальных историй**.
- До **150 слов и 1500 знаков** на историю после объединения пробелов. Цифры допустимы.
- Пустые строки и строки комментариев с `#` не озвучиваются. Дубликаты после
  нормализации пробелов пропускаются; управляющие символы и коды оформления запрещены.
- Старый формат без заголовка: одна история на строку.
- Для многострочных историй первая строка — `# format: blocks`, между историями — `---`.

```text
# format: blocks
Шахтёр обещал вернуться, как найдёт алмазы.
Нашёл. Теперь ищет выход.
---
Другая история, которую вы добавили сами.
```

Встроенный русский набор доступен при русском языке Minecraft, системной локали
Java или кириллице в сообщении/расшифровке голоса игрока. Определение по буквам
приблизительное. Пользовательский файл доступен при любом языке.

## Локальный голос на macOS

Без ключа Inworld Олег озвучивает свои обычные реплики установленным русским
голосом macOS через `/usr/bin/say`. Синтез работает без сети и загрузки голосов.
Звук проходит через обычный проигрыватель мода: источник — Олег, учитываются
расстояние и громкость голоса. Ключ Inworld, если задан, сохраняет приоритет.
Распознавание речи с микрофона по-прежнему требует Inworld; эта возможность
добавляет только бесплатную озвучку ответов.

«Поведение» → «Голос macOS без ключа Inworld» — переключатель, по умолчанию
включён. В локальном конфиге — `macosVoice = true`; прежняя настройка
`windowsVoice` продолжает управлять голосом Windows.

Если установлен Yuri, используется он; иначе — первый доступный русский голос,
например Milena. Если русского голоса нет или системный синтез недоступен,
появится одна подсказка за запуск игры: проверить русский голос в настройках
универсального доступа macOS либо указать ключ Inworld. Текстовые ответы
продолжают работать. Мод сам голоса не устанавливает и английский голос
для русских реплик не подставляет.

Текст передаётся процессу через стандартный ввод без оболочки. Системные
речевые команды в двойных квадратных скобках нейтрализуются. Синтез выполняется
в фоне; временные файлы списка голосов и WAV удаляются после чтения, в том числе
при ошибке. Отдельного архива реплик или аудио эта возможность не создаёт.

Проверки: `./gradlew build`, затем `./gradlew runGameTestServer
-PgameTestClasses=CompanionMacOsVoiceTests,CompanionWindowsVoiceTests`.
Для отдельной проверки без запуска Minecraft: скомпилируйте `MacOsVoice.java`,
`MacOsVoiceHint.java`, `SpeechEngine.java`, `VoicePcm.java` и
`src/test/macos/MacOsVoiceCheck.java`, затем запустите `MacOsVoiceCheck`.
Флаг `--live` дополнительно синтезирует тестовую русскую фразу без сети.
