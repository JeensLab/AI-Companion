# AI Companion — Олег

ИИ-компаньон для одиночной игры в **Minecraft Java Edition 1.21.1** с **NeoForge**.
Версия мода: **0.0.1**. Номер меняется только по явному решению владельца.

Олег общается по-русски, следует за игроком, добывает ресурсы, создаёт предметы по настоящим рецептам, переносит вещи, работает с сундуками и печами, строит дома по схемам и помогает в бою. Возможности ограничены доступными материалами и маршрутами; полноценная самостоятельная игра ещё не реализована.

## Установка

1. Подготовьте отдельный профиль Minecraft **1.21.1** с NeoForge **21.1.262 или совместимым более новым 21.1.x**.
2. Откройте **Releases** справа на странице и скачайте `aicompanion-0.0.1.jar` из **Assets**.
3. Положите JAR в папку `mods` этого профиля и запустите игру. Для экспериментов используйте копию мира.
4. Откройте настройки AI Companion и введите **свой** ключ OpenRouter и модель. Для голоса добавьте **свой** Inworld Basic credential и voice ID. В опубликованном проекте чужих ключей нет.

**Code → Download ZIP** скачивает исходники для разработки. Для игры нужен JAR из Releases или самостоятельная сборка.

## Управление

- **C** — чат и доступ к настройкам.
- **J** — задачи, их состояние, приоритет и отмена.
- **V** — удерживать для записи голоса, отпустить для отправки.
- **ПКМ по Олегу** — его инвентарь.
- **G** — маркер компаньона.

Клавиши размещения схемы описаны ниже. Все клавиши можно изменить в настройках управления. Например: «следуй за мной», «стой здесь», «иди ко мне», «добудь 10 камня», «сделай себе каменную кирку», «сложи ресурсы в сундук». Некоторые прямые команды работают без OpenRouter; свободный диалог и сложные планы требуют настроенного провайдера. Голос требует Inworld. Условия и стоимость внешних сервисов определяются самими провайдерами.

## Постройки по схемам

Олег строит дома не по встроенному чертежу, а по схемам, которые вы кладёте в папку `mods/oleh_ai_schemas` профиля Minecraft. Папка создаётся при первой просьбе. Подходят файлы Litematica (`.litematic`), WorldEdit (`.schem`), старого MCEdit/Schematica (`.schematic`) и структурного блока (`.nbt`). Схемы старых версий игры обновляются автоматически.

1. Попросите: «построй дом» или назовите схему: «построй дом castle». Если схем в папке нет, Олег строит стандартный деревянный дом 5×5 (пол, стены с тремя окнами, крыша из плит с навесом, ступенька и дверь с северной стороны). Место для него выбирается так же.
2. В мире появится полупрозрачная схема, как в Litematica. Она следует за прицелом.
   - **Enter** — строить здесь.
   - **R** — повернуть.
   - **M** — отразить.
   - **[** и **]** — другая схема из папки.
   - **Стрелки**, **Page Up** и **Page Down** — сдвинуть на блок; после этого схема перестаёт следовать за прицелом.
   - **H** — снова следовать за прицелом.
   - **Backspace** — отмена.

   Эти клавиши можно переназначить в настройках мода (кнопка «Клавиши схем») или в «Управление → Назначение клавиш», раздел «ИИ-компаньон».
3. Олег сам добывает и крафтит материалы партиями по рецептам, ломает блоки мира, которые мешают схеме, ставит временные леса для высоких стен и строит до последнего блока. Пока стройка идёт, недостающая часть видна полупрозрачной.

Ограничения:

- Сундуки и другие контейнеры с вещами, неразрушимые блоки и слишком твёрдые без инструмента блоки Олег не ломает. Он остановится и скажет, что мешает.
- Чего его умения добыть не могут (например, стекло: песок он пока не копает), он перечислит. Положите это в его инвентарь и скажите «дострой дом».
- Если нужной породы дерева рядом нет, он строит из той, что есть, и предупреждает об этом. Траву и подзол он заменяет землёй.
- Содержимое сундуков, надписи и другие данные блоков из схемы не переносятся.
- Размер схемы — до 1 000 000 клеток, примерно куб 100×100×100.

«Дострой дом» продолжает сохранённую стройку на том же месте, в том числе после выхода из мира.

## Конфиденциальность

Ключи вводятся локально и хранятся в `config/aicompanion-client.toml` папки Minecraft. Этот файл, его резервные копии, миры, журналы и прежняя локальная история Git не включены в публикацию.

При включённых функциях OpenRouter получает текст диалога и игровой контекст (например, инвентарь и обстановку); Inworld получает аудио для распознавания и текст для озвучки. Не вводите секреты в игровой чат. Это обращения к выбранным провайдерам, а не отправка ключей автора мода другим игрокам.

Локальная диагностика включена по умолчанию и может содержать разговоры, координаты и инвентарь. Чтобы отключить новые записи, задайте `diagnosticLogging = false` в локальных настройках. Не публикуйте эти журналы целиком. Подробности: [SECURITY.md](SECURITY.md).

## Разработка и проверки

Нужны **JDK 21** и интернет для первоначальной загрузки зависимостей. В проекте закреплены NeoForge 21.1.262 и Gradle Wrapper.

Windows:
```powershell
.\gradlew.bat build
```

Linux/macOS:
```sh
./gradlew build
```

Готовый мод: `build/libs/aicompanion-0.0.1.jar`. Для тестового игрового клиента: `runClient`; для механических GameTest: `runGameTestServer`. Есть отдельные сценарии в `scripts/verify*.ps1`; они используют локальные временные каталоги и некоторые требуют уже загруженных зависимостей. Тестовые классы и тестовые структуры исключены из игрового JAR. Сборка и механические проверки не требуют ключей провайдеров.
