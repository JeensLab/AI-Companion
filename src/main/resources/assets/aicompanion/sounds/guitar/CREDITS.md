# Guitar recordings / Записи гитары

Real recordings of solo acoustic (classical) guitar, instrumental only, taken from Wikimedia Commons.
Every file here was changed in the same way: mixed down to mono, silence trimmed at both ends, loudness evened out
(EBU R128, −17 LUFS), a short fade added at the end, re-encoded as Ogg Vorbis 32 kHz. The changed files keep the
licence of their source; for CC BY-SA sources the changed files are shared under the same CC BY-SA licence.

These two stay in the JAR as the standard fallback while the player's folder `config/aicompanion/music` is empty
(entity/CompanionMusicLibrary). They were re-encoded once more at a lower bitrate (Ogg Vorbis, quality 0, mono 32 kHz):
736 021 + 201 147 bytes instead of 1 065 076 + 297 390, about a third smaller, with the audible band kept up to the
16 kHz the format allows at this sample rate.

Настоящие записи сольной акустической (классической) гитары, без слов, с Wikimedia Commons. Каждый файл сведён
в моно, обрезана тишина по краям, выровнена громкость, добавлено затухание в конце, перекодирован в Ogg Vorbis.
Изменённые файлы распространяются на условиях лицензии исходника (для CC BY-SA — на тех же условиях CC BY-SA).

Эти две записи остаются в JAR как запасные, пока папка игрока `config/aicompanion/music` пуста. Они перекодированы
ещё раз с меньшим битрейтом (Ogg Vorbis, качество 0, моно 32 кГц): 736 021 + 201 147 байт вместо 1 065 076 +
297 390 — примерно на треть меньше, слышимый диапазон сохранён до 16 кГц, которые допускает формат при такой
частоте дискретизации.

## The five that left the JAR / Пять записей, ушедшие из JAR

The owner's ruling of 13.11: only a couple of standard recordings ship inside the mod, everything else is the player's
folder. These five were in the JAR before and are not any more; they stay under the same licences and can be put into
`config/aicompanion/music` from the sources below (the recordings there are the originals, longer and not trimmed: the
game reads a file's length itself, so any Ogg Vorbis file works).

По решению владельца от 13.11 в моде остаются только две стандартные записи, остальное — папка игрока. Эти пять были
в JAR и больше не входят в него; лицензии те же, и их можно положить в `config/aicompanion/music` по ссылкам ниже
(там исходные записи, длиннее и без обрезки: длину игра читает сама, поэтому подходит любой файл Ogg Vorbis).
