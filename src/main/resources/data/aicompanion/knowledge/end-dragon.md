source: https://minecraft.wiki/w/Ender_Dragon https://minecraft.wiki/w/Eye_of_Ender

- Здоровье дракона 200 (100 сердец). Урон по телу сильно снижен, по голове больше. Вредят ему только игроки и взрывы.
- Награда: за первое убийство 12000 опыта и яйцо дракона (в Java яйцо только за первое убийство); за повторных драконов по 500 опыта.
- Кристаллы Энда на обсидиановых столбах лечат дракона. Разрушенный кристалл наносит дракону 10 урона.
- Фазы: кружит, плюётся огненными шарами с ядовитыми облаками, садится на портал выхода (стрелы и трезубцы тогда не работают, бейте в ближнем бою), таранит игрока. Крылья отбрасывают.
- Дыхание дракона собирается стеклянной бутылкой.
- Путь в Энд: око Эндера делается из огненного порошка и жемчуга Края. Брошенное око летит в сторону крепости; шанс разбиться 20%. Для портала нужны 12 глаз; в каждой рамке при генерации с шансом 10% глаз уже стоит. Расстояние до первого кольца крепостей вики не подтвердила.
- Возрождение дракона: 4 кристалла Энда по сторонам выходного портала, около 30 секунд.
- После убийства появляются врата к внешним островам (до 20). Там города Края с шалкерами и кораблями с элитрами.
- Не подтверждено по вики: взрыв кроватей в Энде (по памяти они взрываются как в Незере).
