# Как предложить обновление

Изменения в основной проект принимает владелец репозитория. Публичный доступ позволяет читать исходники и предлагать изменения, но не даёт права записи в основной репозиторий.

1. Нажмите **Fork** на странице проекта, чтобы создать свою копию.
2. Создайте в своей копии отдельную ветку для изменения.
3. Исправьте одну понятную проблему или добавьте одну возможность.
4. Проверьте сборку: `./gradlew build` (Windows: `.\gradlew.bat build`). Нужен JDK 21.
5. Если меняете игровую механику, запустите подходящие GameTest и опишите ручную проверку.
6. Откройте **Pull request** в основной репозиторий. Объясните проблему, результат и проверки.
7. Дождитесь решения владельца. Предложение может быть принято, отклонено или отправлено на доработку.

Текущая версия мода — **0.0.1**. Меняйте её только по прямому указанию владельца.

Для разработки через Codex и Claude Code действуют общие [правила AGENTS.md](AGENTS.md).
Карта кода, выбор проверок и передача задачи между помощниками описаны
в [руководстве по разработке](docs/development.md).

Не включайте ключи OpenRouter/Inworld, настройки Minecraft, переписку, журналы игры, сохранённые миры, личные пути и данные аккаунтов. Для примеров используйте пустые значения и вымышленные данные. Не добавляйте чужие изображения или код без разрешения и указания применимых условий.
