# Ключи и личные данные

Каждый игрок использует свои ключи OpenRouter и Inworld. В исходниках значения ключей по умолчанию пустые. Настройки сохраняются локально в `config/aicompanion-client.toml` папки Minecraft.

Не прикладывайте этот файл, его резервные копии, токены, аудио, сохранённые миры или полные игровые журналы к Issues и Pull Requests. Игровые журналы могут содержать переписку, координаты и инвентарь. Перед публикацией снимков закрывайте ключи, имя аккаунта и другие личные сведения.

Если обнаружен опубликованный ключ, немедленно отзовите его в кабинете провайдера и создайте новый. Удаление строки из последнего файла не удаляет её из истории Git и чужих копий. В публичном Issue опишите проблему без значения ключа; для конфиденциальных сообщений используйте **Security → Report a vulnerability**, если этот способ включён в репозитории.

Долговременная память хранится в сохранённом мире (`aicompanion_bonds`) и попадает туда же, куда попадёт сам мир: воспоминания, последние реплики (известные виды ключей и паролей в них маскируются как «[скрыто]», это не гарантия: нестандартный секрет фильтр может пропустить), ступень отношений, недавние события и время последней встречи. Не прикладывайте такой мир к Issues и Pull Requests. Живой чат уходит в OpenRouter как есть, без маскировки; при сжатии памяти туда повторно отправляются только вытесненные реплики, уже с замаскированными секретами. Отключение переключателя «Память» останавливает запись реплик и воспоминаний, сжатие и подстановку памяти в запросы, но события, ступень отношений и время последней встречи по-прежнему записываются на сервере; «забудь всё» стирает воспоминания, предпочтения и реплики (ступень отношений и дела остаются), удаление мира стирает всё.

Не добавляйте ключи провайдеров в GitHub Actions: обычная сборка и локальные механические GameTest не требуют OpenRouter или Inworld.
